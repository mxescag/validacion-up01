## EJ 1 - Descripción
Pequeña API REST de prueba. Ejercicio validación individual.

La aplicación permite consultar un catálogo de libros, como una biblioteca.

## EJ 1 - Diferencia entre commit y push

`commit` guarda los cambios en local junto con una descripción de éstos, mientras que `push` los sube a un repositorio remoto en Github, que puede ser privado o público.

## EJ 2 - Ramas
`feature/docs` añade el archivo `uso.md` a la carpeta docs. Esta carpeta sirve para guardar la documentación del proyecto.

`feature/openapi` añade el archivo de configuración de `openapi.yaml`, que sirve para crear documentación de la API. 

## EJ 2 - Git merge

`git merge` sirve para añadir los cambios y archivos hechos en una _branch_ diferente a _main_ a ésta, de manera que todo quede junto en la rama _main_ al final.
